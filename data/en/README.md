# Bundled English dictionary

Unmodified SCOWL-derived en_US Hunspell dictionary, version 2020.12.07 (size 60), copied from [dylint-spellcheck](https://github.com/dblock/dylint-spellcheck/tree/main/data/en), which copied it from [rubocop-spellcheck v0.2.0](https://github.com/dblock/rubocop-spellcheck/tree/v0.2.0/data/en). [LICENSE](LICENSE) contains the upstream copyright, redistribution terms, and provenance. The default dictionary ships in the npm package and never downloads resources during linting.
